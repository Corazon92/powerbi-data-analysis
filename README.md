# Power BI Data Analysis

> Collection de rapports Power BI réalisés dans le cadre de travaux de data visualisation et d'aide à la décision.  
> **English version below.**

## Rapports

### Analyse opérationnelle et maintenance

[`reports/operational-maintenance-analysis.pbix`](reports/operational-maintenance-analysis.pbix)

Rapport composé de trois pages :

- **Information Général** — vue synthétique ;
- **Analyse opérationnelle** — analyse de l'activité ;
- **Incidents & Maintenance** — suivi des incidents et de la maintenance.

Le fichier contient son modèle de données et 25 éléments visuels répartis sur les trois pages.

### Tableau d'aide à la décision

[`reports/decision-analysis.pbix`](reports/decision-analysis.pbix)

Exercice Power BI centré sur la construction d'indicateurs et d'une page de décision comprenant cinq éléments visuels.

### Analyse Sample Superstore

[`reports/superstore-analysis.pbix`](reports/superstore-analysis.pbix)

Rapport en trois étapes consacré à l'analyse d'un jeu de données commercial de démonstration. Les trois pages contiennent respectivement 3, 4 et 4 éléments visuels.

## Compétences mises en œuvre

**Power BI · Power Query · modélisation de données · indicateurs · tableaux de bord · visualisation · analyse opérationnelle**

## Provenance des données

Ces rapports ont été réalisés pendant des exercices pédagogiques. Les jeux de données sources ont été fournis pour les cours ou utilisés comme données de démonstration ; ils ne sont pas présentés comme des données créées personnellement.

Les fichiers publiés ont été contrôlés avant mise en ligne afin d'écarter les chemins personnels, identifiants et secrets détectables.

# English version

This repository contains Power BI reports created for data-visualization and decision-support coursework.

- **Operational and maintenance analysis:** three pages covering general information, operations, incidents and maintenance.
- **Decision analysis:** a compact dashboard exercise built around decision indicators.
- **Sample Superstore analysis:** a three-step analysis of a demonstration retail dataset.

The source datasets were provided for coursework or used as demonstration data. The repository presents the report design, data modeling and visualization work without claiming ownership of the underlying datasets.
